A mobile-first progressive web application (PWA) tailored for sourcing executives and buyers attending major international trade fairs (SIAL, Anuga, Sirha, Asian Food Expo). Features AI-powered business card scanning via **Gemini Flash**, live voice dictation, multi-photo capture, and instant formatted Excel exports.

---

## 🌟 Highlights

- **Multimodal AI Business Card Scanner**: Captures card photos and accurately extracts contact names, job titles, emails, phone numbers, booth numbers, and web domains using Gemini Flash.
- **Live Voice-to-Text Dictation**: Enables hands-free recording of booth meeting notes directly on the exhibition floor.
- **High-Resolution Photo Gallery**: Attach multiple product and packaging snapshots per booth visit.
- **Offline-First PWA**: Operates smoothly in exhibition halls with spotty or zero network connectivity; synchronizes automatically when online.
- **Instant Excel Synthesis**: Exports consolidated visit reports with embedded contact tables and follow-up flags.

---

## 🚀 Getting Started

```bash
git clone https://github.com/Djkawada/trade-report-app.git
cd trade-report-app
npm install
npm run dev
```
Open `http://localhost:5173` on your desktop or mobile browser.
